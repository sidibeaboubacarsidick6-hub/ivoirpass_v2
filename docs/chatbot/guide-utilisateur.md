# Guide utilisateur IvoirPass

Ce document regroupe l'ensemble des procédures d'utilisation de la plateforme IvoirPass pour les organisateurs, les acheteurs et les agents de scan.

---

## Création d'un compte organisateur

**Comment créer un compte organisateur sur IvoirPass ?**

1. Sur la page d'accueil IvoirPass, allez dans « Espace organisateur ».
2. Si vous n'avez pas de compte, cliquez sur « Créer un espace organisateur ».
3. Renseignez vos informations personnelles.
4. Lisez et acceptez les conditions d'utilisation et la politique de confidentialité.
5. Cliquez sur « Créer mon espace organisateur ».

**Important :** une adresse e-mail ne peut servir à créer qu'un seul compte organisateur.

**Comment se connecter à mon espace organisateur ?**

Allez dans « Espace organisateur », entrez votre e-mail et votre mot de passe, puis validez.

---

## Certification du compte (KYC)

**Pourquoi dois-je certifier mon compte ?**

La certification (vérification KYC) est obligatoire avant toute publication d'événement payant. Elle permet de vérifier votre identité conformément à la réglementation.

**Comment certifier mon compte organisateur ?**

1. Connectez-vous à votre espace organisateur.
2. Allez dans « Mon profil ».
3. Allez dans « Organisation », puis « Compléter mon profil organisateur ».
4. Dans la section « Vérification KYC », ajoutez votre pièce d'identité.
5. Enregistrez.

Votre compte sera certifié par l'équipe IvoirPass après vérification des documents.

---

## Publier un événement

**Comment publier un événement sur IvoirPass ?**

1. Dans votre espace organisateur, allez dans « Créer un événement ».
2. Saisissez les informations de votre événement.
3. Si votre événement dure plus d'un jour, utilisez le « Tunnel multi-jours » situé en haut de la page.
4. Enregistrez en « Brouillon » pour continuer plus tard, ou cliquez sur « Publier » pour le rendre visible dans la section « Événements ».

**Où voir les statistiques de mes événements ?**

Le Dashboard de votre espace organisateur vous donne les détails sur les ventes, les revenus et les statistiques par événement.

---

## Contrôle d'accès (scan)

**Comment scanner les billets à l'entrée de mon événement ?**

1. Dans votre espace organisateur, allez dans « Scanner QR ».
2. Pour l'événement concerné, cliquez sur « Préparer le scan », puis sur « Démarrer ».

---

## Création d'un agent scan

**Comment créer un agent pour scanner les billets ?**

1. Dans votre espace organisateur, allez dans « Mes événements ».
2. Pour l'événement concerné, cliquez sur l'icône du code QR, puis sur « Créer un nouvel agent scanner ».
3. Renseignez les différents champs, puis cliquez sur « Créer l'agent ».
4. Une fois l'agent créé, cochez la case devant son nom et cliquez sur « Enregistrer l'assignation » pour l'autoriser à scanner.
5. Communiquez à l'agent son e-mail, le mot de passe utilisé pour sa création et l'ID de l'événement.

L'agent se connecte via le lien de l'application scan et peut scanner les tickets des événements auxquels il est assigné.

**Le scan fonctionne-t-il sans connexion internet ?**

Oui. Un code QR valide un jour est scanné une seule fois. Les doublons sont détectés automatiquement. Possibilité de scanner lorsque l'appareil perd la connexion réseau : les scans sont enregistrés localement puis synchronisés dès le retour de la connexion.

## Vendre un produit

**Comment vendre un produit sur la boutique IvoirPass ?**

1. Dans votre espace organisateur, allez dans « Nouveau produit ».
2. Saisissez les informations de votre produit (le choix du type de produit modifie le reste des informations à renseigner).
3. Enregistrez en « Brouillon » pour continuer plus tard, ou cliquez sur « Publier » pour le rendre visible dans « Boutique ».

**Où voir les statistiques de mes produits ?**

Le Dashboard de votre espace organisateur vous donne les détails sur les ventes, les revenus et les statistiques par produit.

**Comment gérer les livraisons de produits physiques ?**

Pour les produits physiques, vous recevrez les commandes et le détail des livraisons par e-mail. Dans votre espace organisateur, allez dans « Livraison à faire ».

---

## Reversement des fonds

**Comment demander un reversement ?**

1. Dans votre espace organisateur, allez dans « Demander reversement ».
2. Choisissez le portefeuille source (événements ou produits).
3. Saisissez les détails du reversement (méthode, numéro Mobile Money, nom du bénéficiaire).
4. Vérifiez l'exactitude des informations.
5. Cliquez sur « Soumettre la demande ».
6. Saisissez le code à 6 chiffres reçu par e-mail ou SMS.
7. Cliquez sur « Valider ».

Vous recevrez votre reversement.

**Quel est le montant minimum pour demander un reversement ?**

Le solde de votre wallet doit atteindre au moins 5 000 FCFA pour pouvoir demander un reversement.

---

## Codes de billets gratuits

**Comment générer des codes de billets gratuits ?**

1. Dans votre espace organisateur, allez dans « Mes événements ».
2. Pour l'événement concerné, cliquez sur l'icône de cadeau.
3. Dans « Ajouter des bénéficiaires », renseignez les différents champs en respectant le format indiqué.
4. Cliquez sur « Générer les codes ».

---

## Achat de tickets événement

**Comment acheter un ticket sur IvoirPass ?**

1. Sur la page d'accueil IvoirPass, cliquez sur « Événements ».
2. Trouvez votre événement :
   - En déroulant la liste.
   - En filtrant par catégorie.
   - En utilisant la barre de recherche (nom de l'événement ou mot-clé).
3. Cliquez sur l'événement, puis dans « Billets », sélectionnez « Acheter mes billets ».
4. Saisissez vos informations, choisissez vos billets, puis procédez au paiement.

Vous recevrez par e-mail vos tickets au format PDF avec code QR.

**Quels sont les moyens de paiement acceptés ?**

- Mobile Money : Wave, Orange Money, MTN Mobile Money, Moov Money.
- Carte bancaire : Visa, Mastercard.

---

## Accès à l'événement

**Comment entrer à l'événement ?**

Présentez votre code QR à l'entrée de l'événement pour qu'il soit scanné.

**Important :** le code est scanné une seule fois pour les événements d'un jour. Ne le partagez pas.

**Que se passe-t-il si mon QR code est partagé ?**

Le premier scan est accepté. Toute tentative suivante avec le même QR code est automatiquement refusée. IvoirPass détecte automatiquement les doublons.

---

## Achat de produits (boutique)

**Comment acheter un produit sur la boutique ?**

1. Sur la page d'accueil IvoirPass, cliquez sur « Boutique ».
2. Trouvez votre produit :
   - En déroulant la liste.
   - En filtrant par catégorie.
   - En utilisant la barre de recherche.
3. Cliquez sur le produit, puis sur « Acheter maintenant ».
4. Saisissez vos informations, choisissez le format souhaité, puis la quantité.
5. Vérifiez le montant total, puis cliquez sur « Payer ».

**Produit numérique :** vous recevrez par e-mail le lien de téléchargement. Le lien est personnel : 3 téléchargements maximum, valable 48 heures.

**Produit physique :** renseignez le champ « Adresse de livraison ». Le vendeur vous contactera pour la livraison. Les frais de livraison sont à votre charge.

---

## Événement annulé

**Que se passe-t-il si un événement est annulé ?**

Les acheteurs sont prévenus automatiquement par e-mail et leurs billets sont refusés au scan. Le remboursement se fait via l'organisateur.

---

## Paiements sécurisés

**Mes paiements sont-ils sécurisés ?**

Oui. Chaque paiement Mobile Money est vérifié côté serveur avant l'émission du ticket. Le prestataire technique de paiement est agréé par la BCEAO.
