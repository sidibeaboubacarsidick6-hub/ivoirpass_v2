Pour les organisateurs

1. Création de compte et connexion
  • Sur la page d'accueil IvoirPass, allez dans « Espace organisateur ».
  • Connectez-vous avec votre e-mail et votre mot de passe. Si vous n'avez pas de compte, cliquez sur « Créer un espace organisateur ».
  • Renseignez vos informations, lisez et acceptez les conditions d'utilisation et la politique de confidentialité.
  • Cliquez sur « Créer mon espace organisateur ».
2. Certification de compte

Obligatoire avant toute publication

  • Connectez-vous à votre espace organisateur.
  • Allez dans « Mon profil ».
  • Allez ensuite dans « Organisation » puis dans « Compléter mon profil organisateur ».
  • Dans « Vérification KYC », ajoutez votre pièce d'identité puis enregistrez.
  • Votre compte sera certifié par IvoirPass.
3. Publier un événement
  • Dans votre espace organisateur, allez dans « Créer un événement ».
  • Saisissez les informations de votre événement. Si votre événement dure plus d'un jour, utilisez le « Tunnel multi-jours » situé en haut de la page.
  • Enregistrez en « Brouillon » pour continuer plus tard, ou cliquez sur « Publier » pour le rendre visible dans la section « Événements ».
  • Le Dashboard de votre espace organisateur vous donne les détails sur les ventes, les revenus et les statistiques par événement.
4. Contrôle d'accès (scan)
  • Dans votre espace organisateur, allez dans « Scanner QR ».
  • Pour l'événement concerné, cliquez sur « Préparer le scan » puis sur « Démarrer » pour commencer à scanner.
5. Création d'un agent scan
  • Dans votre espace organisateur, allez dans « Mes événements ».
  • Pour l'événement concerné, cliquez sur l'icône du code QR puis sur « Créer un nouvel agent scanner ».
  • Renseignez les différents champs, puis cliquez sur « Créer l'agent ».
  • Une fois votre agent créé, cochez la case devant votre agent et cliquez sur « Enregistrer l'assignation » pour l'autoriser à scanner.
  • Communiquez à l'agent l'e-mail, le mot de passe utilisé pour sa création et l'ID de l'événement. À l'aide du lien de l'application scan, l'agent se connecte et peut scanner les tickets des événements auxquels il est assigné.
À savoir : Un code QR valide un jour n'est scanné qu'une seule fois — les doublons sont détectés automatiquement. Il est possible de scanner lorsque l'appareil perd la connexion réseau : les scans sont enregistrés puis synchronisés dès le retour de la connexion.
6. Vendre un produit
  • Dans votre espace organisateur, allez dans « Nouveau produit ».
  • Saisissez les informations de votre produit (le choix du type de produit modifie le reste des informations à renseigner).
  • Enregistrez en « Brouillon » pour continuer plus tard, ou cliquez sur « Publier » pour le rendre visible dans la « Boutique ».
  • Le Dashboard de votre espace organisateur vous donne les détails sur les ventes, les revenus et les statistiques par produit.
  • Pour les produits physiques, vous recevrez les commandes et le détail des livraisons par mail. Dans votre espace organisateur, allez dans « Livraison à faire ».
7. Reversement
  • Dans votre espace organisateur, allez dans « Demander reversement ».
  • Choisissez le portefeuille source (événements ou produits).
  • Saisissez les détails du reversement (méthode de reversement, numéro Mobile Money, nom du bénéficiaire).
  • Vérifiez l'exactitude des informations.
  • Cliquez sur « Soumettre la demande ».
  • Saisissez le code à 6 chiffres qui vous a été envoyé par e-mail ou par SMS. Cliquez ensuite sur « Valider ». Vous recevrez votre reversement.
8. Codes de billets gratuits
  • Dans votre espace organisateur, allez dans « Mes événements ».
  • Pour l'événement concerné, cliquez sur l'icône de cadeau.
  • Dans « Ajouter des bénéficiaires », renseignez les différents champs en respectant le format indiqué, puis cliquez sur « Générer les codes ».

Pour les acheteurs

1. Acheter un ticket d'événement
  • Sur la page d'accueil IvoirPass, cliquez sur « Événements ».
  • Vous pouvez ensuite :
    • Dérouler la liste des événements en cherchant le vôtre.
    • Sélectionner la catégorie de votre événement dans « Filtres ».
    • Saisir le nom de l'événement ou un mot-clé dans la barre de recherche.
  • Cliquez sur l'événement, puis dans la section « Billets », sélectionnez « Acheter mes billets ».
  • Saisissez vos informations, choisissez vos billets, puis procédez au paiement.
  • Vous recevrez par mail vos tickets au format PDF avec code QR.
2. Accès à l'événement

Présentez votre code QR à l'entrée de l'événement pour qu'il soit scanné. Le code est scanné une seule fois pour les événements d'un jour : ne le partagez pas.

3. Acheter un produit
  • Sur la page d'accueil IvoirPass, cliquez sur « Boutique ».
  • Vous pouvez ensuite :
    • Dérouler la liste des produits en cherchant le vôtre.
    • Sélectionner la catégorie de votre produit dans « Filtres ».
    • Saisir le nom du produit ou un mot-clé dans la barre de recherche.
  • Cliquez sur le produit, puis cliquez sur « Acheter maintenant ».
  • Saisissez vos informations, choisissez le format souhaité, puis la quantité.
  • Vérifiez le montant total puis cliquez sur « Payer ».
  • Vous recevrez par mail le lien de téléchargement (produit numérique).
À savoir : Pour les produits physiques, renseignez le champ supplémentaire « Adresse de livraison » — le vendeur vous contactera pour la livraison. Pour les produits numériques, le lien est personnel (3 téléchargements maximum, valable 48 h).
